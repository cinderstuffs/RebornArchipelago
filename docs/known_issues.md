This list will be updated on every new release. If you found a bug that isn't listed here, please send me a message.

## High priority

- The apworld has yet to be tested in an actual multiworld with other games. Tests made so far were using a local multiworld with only one instance of Pokémon Reborn.

- The game doesn't detect when the goal is achieved yet.

- The game is still linear and follows the vanilla storyline; there's no open world feature yet. Read [the story gate guide](story_gate.md) for more information.

- In Obsidia Ward, when Obsidia Park is taken by Team Meteor, Florinia requests you to go get TMX Cut at Coral Ward, even if you own it. In the future, she will move and give you access to the park. Coral Ward Amaria's check (which is TMX Cut's location) should still be available.

## Mid priority

- PopTracker isn't always accurate when it comes to missed checks. It's because most checks' availability rely on story flags, instead of items, which is harder to track.

## Low priority

- If you receive an item you already own 999 instances of, you will not receive it, and a message will warn you about that. Realistically, it would only occur if you farm or buy lots of instances of a filler item.
